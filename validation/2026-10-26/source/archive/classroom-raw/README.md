Workspace
=========

This is your workspace for Introduction to Interpretability for Language
Models. It is yours to do with as you wish: You have sole access to the
contents of this directory, and you may spin up/tear down notebooks as much as
you'd like for the duration of the workshop.

Data
----

Under `data/`, you'll find all of the files we'll use in our sessions. This
directory is **read-only**, meaning you won't be able to save anything in it.
If you'd like to do that, make your own directory with the "New Folder" button
on JupyterHub.

Models
------

The following models are available for use:

- [gpt2](https://huggingface.co/openai-community/gpt2)
- [distilgpt2](https://huggingface.co/distilbert/distilgpt2)
- [bert-base-uncased](https://huggingface.co/mental/mental-bert-base-uncased)
- [Qwen2.5-1.5B-Instruct](https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct)
